🚀 Terbitkan Link

Agar link tampil di semua murid, tempel kodenya ke app.js.

  1. Klik Salin kode di bawah.
  2. Buka file app.js di GitHub, lalu ganti bagian DEFAULT_LINKS dengan kode yang disalin.
  3. Klik Commit changes, tunggu 1–2 menit, lalu muat ulang websitenya (Ctrl+F5).
